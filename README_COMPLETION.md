# PacStudent 使用说明

项目目录：D:\Codex\2026-09-29\qi\outputs\Pacstudent_Assess4
编辑器：Unity 6000.6.0f1（按你的要求使用电脑现有版本）。原压缩包仍保留在 Downloads。

## 打开与运行

在 Unity Hub 的项目列表打开 Pacstudent_Assess4。打开 Assets/Scenes/StartScene.unity，点击 Play。
Windows 独立版本：D:\Codex\2026-09-29\qi\outputs\PacStudent-Windows\PacStudent.exe。

- WASD 或方向键：按住移动，按得越久走得越远。松开所有方向键后，仅走完当前一格便停止（正常速度下最多约 0.17 秒），不会继续走完整条路。转弯需要保持按住目标方向；目标方向被墙挡住时停下。
- Level 1：经典关卡。
- Level 2：能量脉冲关卡。普通豆增加 5 能量、能量豆增加 25，能量最多 100。
- 第二关按空格：消耗 50 能量，让 6 格范围内的非死亡幽灵受惊 5 秒。
- EXIT：回到主菜单。

## 已实现的游戏流程

菜单保留你的标题、副标题和角色美术；添加会移动的 UI 边框、两个关卡入口及每关独立的最高分和对应时间。
关卡包含 3、2、1、GO 倒计时、3 个生命图标、六位分数、分/秒/百分秒计时、受惊倒计时和幽灵编号。
沿用你的手工地图、四个幽灵、玩家和音效。玩家逐格线性插值移动，墙壁阻挡，左右隧道互相传送。
普通豆 10 分，能量豆 50 分，樱桃 100 分，受惊幽灵 300 分。
能量豆使幽灵受惊 10 秒。受惊时保留四个角色各自的外形，添加青色调和编号后的 !；最后 3 秒闪烁并显示 !!，随后恢复正常。之前全部变成黄色是共用受惊动画的设计，本次改为更容易区分的表现。幽灵死亡后穿墙回到出生点再复活。
四个幽灵分别逃离、接近、随机移动、顺时针巡逻外侧区域；禁止普通状态重新进出生区和使用传送通道。
加入移动尘土、撞墙粒子、死亡粒子、状态音乐切换、移动吃豆/空走两种音效，以及穿越地图中心的随机樱桃。
死亡时停下幽灵并扣命，重生后按住方向键继续移动。吃完所有豆显示 GAME COMPLETE! 和 CONGRATULATIONS!；生命归零显示 GAME OVER。两种结算均在 3 秒后返回菜单。
最高分相同的时候，只更新更快的完成时间。

## 创新关卡说明

能量脉冲让玩家在追击过程中作出取舍：积攒能量保留一次逃生机会，或主动接近多个幽灵，使用范围脉冲制造得分机会。
它只影响附近幽灵，并且消耗有限的吃豆资源；需要用空格主动触发。第一关保持经典规则。
