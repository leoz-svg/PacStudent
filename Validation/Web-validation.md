# Web 构建验证

日期：2026-09-30；Unity：6000.6.0f1。

- WebGL Release 构建成功，使用 Gzip 和 JavaScript 解压回退，以便静态站点无需自定义 Content-Encoding 响应头也能运行。
- 发布文件约 13 MB；单线程 Web 构建，不依赖跨源隔离响应头。
- 在本地 HTTP 服务下，通过浏览器实际点击加载按钮，Unity 主菜单正常显示。
- 点击 Level 1 后出现开局倒计时和地图。
- 通过浏览器发送 D 键，角色移动并吃豆，得分由 0 变为 10。
- 页面包含加载进度、失败提示、全屏入口、快速指南与完整玩法链接。
- 未验证手机触屏操作；本作要求键盘。浏览器本地纪录与 Windows 版独立。

此前两种分辨率的移动、受惊和胜负逻辑检查见 `Revision/`。本记录不将这些编辑器测试描述为浏览器端的完整测试。

线上部署验证将在发布完成后补充。
