# PacStudent 详细游戏玩法说明

适用版本：Assessment 4 v1.3.0 独立地图与完整流程版（2026-10-01）。

## 1. 游戏目标

在迷宫里收集所有普通豆和能量豆，同时尽量保留生命、提高得分。清空这两类豆子即可通关，不需要捕捉全部幽灵，也不要求吃到樱桃。每次进入关卡是一局新游戏，初始拥有 3 条生命。

游戏包含两个独立选择的关卡：Level 1 为基础玩法，Level 2 在基础玩法上增加连击倍率、追猎波次和两档主动脉冲。两个关卡使用不同地图。结算后自行选择再玩一局或返回菜单，不会自动进入下一关。

## 2. 在线试玩与下载启动

网页版发布后可直接点击仓库首页的试玩链接，无需安装 Unity。点击“开始加载游戏”，等待加载完成后点击游戏画面，使其获得键盘焦点。建议用带键盘的电脑；当前没有触屏操作。网页版纪录保存在当前浏览器，和 Windows 版不互通；清除网站数据或使用无痕模式可能使纪录不保留。刷新页面会结束本局。

Windows 下载版：

1. 打开仓库的 [Releases 发布页面](https://github.com/leoz-svg/PacStudent/releases/latest)。
2. 在附件中下载 `PacStudent-Windows.zip`，完整解压到一个文件夹。
3. 双击 `PacStudent.exe` 启动。保留同目录的 `PacStudent_Data`、`UnityPlayer.dll` 等所有文件，不要只复制 exe。
4. 在主菜单点击 Level 1 或 Level 2。
5. 等待 `3 → 2 → 1 → GO!` 倒计时结束，再开始移动。

Windows 下载版不需要安装 Unity。当前游戏面向键盘与鼠标，没有手机触屏控制。

### 主菜单音乐设置

点击主菜单右上角 **SETTINGS** 打开设置面板：

- **BACKGROUND MUSIC：** 点击 ON / OFF 开启或关闭所有背景音乐，包括菜单、开局和两个关卡的状态音乐。
- **MUSIC VOLUME：** 拖动滑块在 0%～100% 之间调节，立即生效。首次运行默认开启、音量 50%；0% 相当于静音。
- 点击 **DONE** 或按 **Esc** 关闭面板并保存。再次进入关卡、返回菜单或重新启动后沿用上次保存的设置。
- 音乐关闭时仍可调整音量，重新开启后使用选择的音量。吃豆、撞墙、死亡等音效不受音乐开关影响。
- 设置面板打开时不能点击后面的关卡按钮。

主菜单与普通游玩音乐改为 HydroGene 的 **8-bit MonsterVania #1**，采用 CC0 许可；受惊和幽灵返回阶段保留原有状态音乐提示。来源与许可见仓库 `THIRD_PARTY_NOTICES.md`。网页版和 Windows 版分别保存自己的设置；浏览器清理网站数据后可能恢复默认值。

## 3. 操作与移动手感

| 动作 | 按键或方式 |
|---|---|
| 向上 | W / ↑ |
| 向左 | A / ← |
| 向下 | S / ↓ |
| 向右 | D / → |
| 停止前进 | 松开所有方向键 |
| 第二关主动脉冲 | 空格 |
| 暂停 / 继续 | Esc，或点击右下角 PAUSE |
| 重开 / 返回菜单 | 暂停菜单内 RESTART LEVEL / MAIN MENU |

**按住才持续移动。** 按住时间越长，移动距离通常越远；松键后角色只走完已经开始的那一格，然后停下，不会自动走完整条走廊。正常速度为每秒 6 格，因此松键后的剩余移动最多约 0.17 秒。很短的轻点仍会完成一格，移动距离以格子为单位。

角色到格子中心后改变方向。需要转弯时保持按住新的方向；若该方向有墙，角色会停下，不会继续沿原方向滑走。同时按住多个方向时，优先响应最近按下且仍然保持的方向。松开全部方向键最容易准确停步。

迷宫左右中间的隧道互相连接：从一端走出会出现在另一端。普通活动中的幽灵不使用隧道，可以利用它摆脱追击。墙壁和幽灵出生区的门不能穿过。

游玩中按 Esc 或点击 PAUSE 暂停，角色、计时、受惊、连击窗口、追猎和冷却都会冻结。点击 RESUME 或再按 Esc 继续。暂停菜单可开关音乐和调节音量，设置会保存；RESTART LEVEL 重开当前关卡，MAIN MENU 返回主菜单，两者都会放弃当前局。开局倒计时、死亡动画和结算期间不能再次暂停。

## 4. 界面说明

| 显示 | 含义 |
|---|---|
| LEVEL | 当前关卡 |
| LIVES | 剩余生命；沿用原项目的生命图案 |
| SCORE | 本局累计得分 |
| TIME | 有效游玩时间，格式为分:秒:百分秒 |
| SCARED TIME | 能量豆提供的全局受惊剩余时间 |
| 幽灵上方编号 | 用于区分 1～4 号幽灵及状态标记 |
| ENERGY（仅第二关） | 当前能量、脉冲档位与冷却 |
| RECHARGE / GET READY / HUNT! | 第二关当前波次与倒计时 |
| COMBO | 收豆连击与倍率，时间条耗尽后重置 |
| PELLETS LEFT | 距离通关还剩多少豆子 |

开局倒计时、死亡等待和结算期间不会继续增加游玩计时。第二关脉冲产生的是附近幽灵的局部受惊状态，不会写入全局 SCARED TIME；请结合幽灵旁的 `!` / `!!` 判断。

## 5. 道具与计分

| 收集或行动 | 得分 | 其他效果 |
|---|---:|---|
| 普通豆 | 10 | 第二关增加 5 能量 |
| 能量豆 | 50 | 全局受惊 10 秒；第二关增加 25 能量 |
| 樱桃 | 100 | 额外奖励，不是通关必要条件 |
| 捕捉受惊或恢复中的幽灵 | 300 | 幽灵返回出生点 |

第二关连击倍率只作用于豆子得分：第 10 颗起 ×2、第 25 颗起 ×3，能量收入不变；樱桃和捕捉幽灵不参与倍率。

樱桃会周期性从地图外侧穿越地图中心，移动中碰到它即可得分。它被吃掉或离场后，约 5 秒再出现；不必为了追樱桃冒险闯入幽灵群。

再次吃能量豆会把全局受惊时间至少恢复到 10 秒，不会每次累加 10 秒。普通豆和能量豆被吃掉后，本局死亡重生不会重新出现。

## 6. 四只幽灵及状态

### 正常状态的行为

| 编号 | 行为倾向 |
|---|---|
| 1 | 倾向选择远离玩家的方向；仍然会伤害玩家 |
| 2 | 倾向选择接近玩家的方向，形成追击 |
| 3 | 在可行方向中随机移动 |
| 4 | 按顺时针顺序巡逻外侧四个角落区域 |

这些是方向选择策略，不代表每一步都能保证直线接近或远离。墙壁、路口和尽量不立即掉头的规则会影响实际路线。正常幽灵的速度约为玩家的 90%。第二关 HUNT 阶段，正常幽灵会集中追击，速度升到玩家的 98%；受惊状态仍优先。

### 受惊、恢复与返回出生点

- **受惊：** 保留四只幽灵各自的形状，添加青色调，编号后显示 `!`；移动速度降低，并倾向远离玩家。接触它可以获得 300 分。
- **恢复：** 受惊剩余时间不超过 3 秒时闪烁，并显示 `!!`。此时仍能捕捉，但很快会恢复危险的正常状态。
- **被捕捉：** 显示返回状态，编号后为 `x`，穿墙回出生点。途中不能重复得分，也不会扣玩家生命。回到出生点后重新活动；如果受惊效果尚未结束，可能继续处于受惊或恢复状态。

旧版本所有幽灵统一变黄，是共用受惊动画的表现，并非额外生成同一种怪物。当前版本已经改为保留个体外形，方便追踪每只幽灵。

## 7. Level 2：能量追猎

### 独立地图：双环迷宫

第二关共 235 颗普通豆和能量豆。外圈适合撤退与连续收豆，内圈提供多条换线机会；中央两条横向捷径靠近幽灵出口，路短但风险更高。四颗能量豆中，两颗位于环路连接处，两颗靠近中央出口。左右隧道保留，通关仍只要求清空所有豆子。[地图与流程说明](EXPANSION_v1.3.md)。

### 连续收豆

- 每次吃到一颗新豆子，连击计数加一，维持窗口重新变为 3 秒。
- 连续 10 颗开始，豆子得分 ×2；连续 25 颗开始 ×3，上限为 ×3。
- 第 10 和第 25 颗当场享受新倍率。普通豆基础 10 分，能量豆基础 50 分。
- 3 秒没有吃到新豆子，或受到伤害，连击清零。经过空走廊不算收豆。
- 倍率只影响普通豆和能量豆的分数，能量收入、樱桃和捕捉幽灵分数不变。
- 左侧连击条显示剩余维持时间；走安全路线比为了连击送命更重要。

### 30 秒波次

| 阶段 | 时长 | 变化 |
|---|---:|---|
| RECHARGE | 20 秒 | 四只幽灵采用各自原有策略，适合收豆和攒能量 |
| GET READY | 3 秒 | 提醒追猎即将开始，预留逃生路线或脉冲 |
| HUNT! | 7 秒 | 正常幽灵改为追踪玩家，速度由玩家的 90% 升到 98% |

追猎中的正常幽灵编号变为红色并带 `>`。吃能量豆或释放脉冲后，受惊幽灵仍减速逃跑，`!` / `!!` 提示优先。返回出生点的幽灵不参与追猎。

波次只在实际游玩时推进。受伤会重置为 20 秒收集阶段，避免复活后立即再次进入围攻。

### 两档脉冲

| 能量 | 空格效果 | 消耗 |
|---|---|---:|
| 0～49 | 不释放，提示继续收集 | 0 |
| 50～99 | 普通脉冲：6 格半径、5 秒受惊 | 50 |
| 100 | 强化脉冲：10 格半径、7 秒受惊 | 100 |

普通豆提供 5 能量，能量豆提供 25，上限 100。倍率不会额外增加能量。成功释放后有 4 秒冷却，期间重复按空格不会消耗能量；按住空格不会自动连发。

脉冲范围按直线距离计算，可以穿墙，不影响返回出生点的幽灵。范围内没有目标时仍会消耗能量，界面显示本次命中的幽灵数量。脉冲不会缩短已有的更长受惊效果。

受伤保留已积攒的能量并清除冷却；退出或重新开始关卡时能量回到 0。

### 读懂界面

- 左侧：当前波次、倒计时、连击倍率、收豆数量和维持时间。
- 右侧：剩余通关豆子、能量条、技能档位和即时提示。
- 底部：精确能量、脉冲就绪状态或冷却时间。
- 开局倒计时：展示收豆连击、能量与空格脉冲提示。

先沿尚未清空的连续走廊积累连击。预警出现时观察幽灵方向：危险贴近就用 50 能量解围；位置安全则可以存到 100，等追猎集中后用强化脉冲反击。不要为了维持倍率冲进即将恢复的幽灵身边。


## 8. 死亡、通关与最高分

碰到正常幽灵会失去 1 条生命，播放死亡效果，并短暂停住游戏。有剩余生命时，玩家和幽灵回到出生位置；本局得分、已收集的豆子和已用时间保留，受惊效果清除。

**成功：** 吃完所有普通豆和能量豆，显示 `GAME COMPLETE!` 和 `CONGRATULATIONS!`。

**失败：** 生命减为 0，显示 `GAME OVER`。

两种结算都会冻结关卡，展示得分、用时、收豆数和捕捉幽灵数；第二关还显示最高连击、脉冲次数及命中总数。结算页保持显示，等待选择 PLAY AGAIN（重试）或 MAIN MENU（返回菜单），并比较本关纪录。分数高于原纪录时更新最高分及其对应时间；分数相同时只接受更短的用时。失败结算也能更新纪录，所以菜单时间表示“该最高分对应的用时”，不一定是一次通关时间。从暂停菜单提前重开或退出，不会触发本局结算保存。

两个关卡的纪录独立保存在本机，没有在线排行榜或跨设备同步。关卡进行中的进度不保存，关闭游戏后需要重新开始。

## 9. 实用技巧

1. 先规划一片区域的收豆路线，避免反复经过已经清空的走廊。
2. 使用轻点完成一格调整，接近路口时注意保持正确的转弯方向。
3. 留意 2 号追击幽灵，别认为 1 号“远离玩家”就可以安全碰触。
4. 能量豆既是通关目标，也是应急保护；观察附近幽灵位置后再吃。
5. 出现 `!!` 时优先离开幽灵身边，避免刚结束受惊就发生碰撞。
6. 第二关不要对空处频繁放脉冲，积攒资源可以提高后半局的生存机会。

## 10. 常见问题

**为什么松开键后还走了一点？** 为了保持网格对齐，当前已经开始的一格会走完。它不会再启动下一格。

**为什么按转弯方向后停住了？** 目标方向被墙挡住。请在可转弯路口操作，或重新按可通行方向。

**为什么有幽灵受惊，但 SCARED TIME 没有数字？** 第二关脉冲只给范围内的幽灵施加局部效果；全局计时只显示能量豆效果。

**能否只下载 exe 发给别人？** 不能。请发送完整的 `PacStudent-Windows.zip`，让对方完整解压。

**下载源码能直接双击运行吗？** 源码需要 Unity 6000.6.0f1。仅体验游戏请下载 Releases 中的 Windows 压缩包。

**在 Unity 里按键没反应？** 确认处于 Play 模式、倒计时已结束，并先点击 Game 视图使其获得键盘焦点。
