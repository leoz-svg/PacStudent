# v1.3：独立地图、暂停与结算

此文档说明 v1.3.0 的独立地图、暂停菜单和完整结算页。

## 第二关：双环迷宫

第二关使用独立地图，第一关地图保留。第二关仍以吃完全部普通豆和能量豆为通关条件。

- 外圈是连续的撤退路线，适合保持收豆连击。
- 内圈与外圈通过多个路口连接，提供换线空间。
- 靠近幽灵房上下出口的两条横向通道是中央捷径，距离较短，但更容易遭遇刚出门的幽灵。
- 两颗能量豆安排在环路连接处，另外两颗靠近中央出口；玩家可以决定何时利用全局受惊突破危险区域。
- 左右中间隧道保留，幽灵房仍不允许玩家进入。
- 地图采用新的青绿色像素墙面，与第一关区分。设计包含 235 颗通关豆子；没有额外任务阻止通关。

原有连击倍率、收集 / 预警 / 追猎波次、普通与强化脉冲继续生效。

## 暂停菜单

游玩中按 **Esc**，或点击右下角 **PAUSE**。

- 暂停会冻结玩家、幽灵、游戏计时、连击窗口、追猎波次、受惊时间和技能冷却。
- **RESUME / Esc**：返回当前游戏。
- **RESTART LEVEL**：放弃当前局，重新进入同一关，重置得分、生命、豆子和能量。
- **MAIN MENU**：放弃当前局并返回主菜单。
- 菜单中可开关背景音乐、调节音量；关闭面板或切换场景时保存，与主菜单设置共用。
- 音乐仍可以播放，方便调节音量；角色移动循环音效暂停。
- 开局倒计时、死亡动画和结算期间不接受再次暂停。

暂停中的重开和回菜单按钮旁会明确提示它们将结束当前局，避免误以为会保存对局进度。

## 完整结算页

通关显示 **GAME COMPLETE! / CONGRATULATIONS!**，生命耗尽显示 **GAME OVER**。

结算页显示：

- 最终得分和本局用时。
- 收集豆子数量、捕捉幽灵数量。
- 第二关最高连续收豆数量、脉冲使用次数 / 命中幽灵总次数；第一关显示剩余生命。
- 新纪录提示；没有刷新纪录时显示已有最高分。

分数记录继续沿用原有规则：分数较高时更新，分数相同时记录较短用时。已有纪录不会清空。

结算后画面保持冻结，等待玩家选择 **PLAY AGAIN** 或 **MAIN MENU**，不再自动倒计时返回。重开与返回菜单都会恢复正常游戏时间流速。
