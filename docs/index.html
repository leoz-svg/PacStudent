READY TO PLAY?

迷宫里见。

收集所有豆子，保住三条生命。第二关加入连击倍率、追猎波次和强化脉冲。

首次加载约 16 MB，完成后点击画面开始操作。

W A S D / ↑ ← ↓ → 按住移动 · 松键停步 · 空格 第二关脉冲

01 / 清空地图

普通豆 10 分，能量豆 50 分，樱桃 100 分。吃完全部豆子即可通关。

02 / 观察幽灵

编号后的 ! 表示可以捕捉，获得 300 分。!! 与闪烁提示受惊即将结束。

03 / 主动反击

Level 2 连续收豆可获 ×2 / ×3 分。追猎前预留脉冲，满 100 能量可释放强化脉冲。

第一次玩？展开快速指南
  1. 加载完成后，在菜单选择 Level 1 或 Level 2，等待 3、2、1、GO!。
  2. 按住方向键移动，松开后走完当前一格便停止；被墙挡住时不会继续沿原方向走。
  3. 正常幽灵会扣命。吃能量豆可使幽灵受惊 10 秒，最后 3 秒闪烁。
  4. 第二关连续 10 / 25 颗豆触发 ×2 / ×3 分数，3 秒未收豆则重置。每轮 20 秒收集、3 秒预警、7 秒追猎。空格消耗 50 能量释放 6 格 / 5 秒脉冲；满 100 能量则释放 10 格 / 7 秒强化脉冲，冷却 4 秒。
  5. 清空豆子显示 GAME COMPLETE；生命耗尽显示 GAME OVER。3 秒后回菜单。
音乐设置、存档与浏览器说明

主菜单右上角 SETTINGS 可开关音乐、调节音量。点击 DONE 或按 Esc 关闭并保存；游戏音效独立保留。新版主旋律为 HydroGene 的 8-bit MonsterVania #1（CC0）。

建议使用桌面 Chrome、Edge 或 Firefox。点击游戏画面后操作；浏览器可能需要这次点击才能播放声音。方向键和空格只有在游戏画面获得焦点时才被拦截。

最高分保存在当前浏览器的本地数据中，与 Windows 版和其他浏览器不互通。无痕模式、清理网站数据或浏览器存储限制可能使纪录不保留。对局进度不保存；刷新页面会重新开始。

如果加载失败，请重新加载页面；也可以下载 Windows 版。网页版需要支持 WebGL 的浏览器和硬件。
